# Event-union hunt, 2026-11-25

A bounded hunt, not a round: no code is merged, the deliverable is queue rows.
It ran after round 47. The run was stopped early by mistake (12:28Z against a
14:21Z stop-new-rounds point) and resumed with an enforced clock; see l1.

## Method

The vendored client names every event it can receive in
`ext/code/lib/opencode/promise/generated/types.d.ts`
(`export type V2Event = ...`, 94 members). For each member, take the literal
`type:` string from its payload type and compare it with the `case '...'`
labels in `ext/code/event.mjs` `translate()`. A type with no case is dropped.

    node - <<'EOF'
    ... read the union, map each member to its type: string, read the cases ...
    EOF

The script is not kept: it is twelve lines and the types file moves under
`bin/postinstall`, so a stored copy would rot. Repeat it by hand.

## Result

29 of 94 types are translated. Of the 65 dropped, most belong to other
clients or to broadcast noise that this UI never draws (`tui.*`, `pty.*`,
`shell.*`, `worktree.*`, `installation.*`, `mcp.*`, `models-dev.*`,
`credential.*`, `integration.*`, `plugin.*`, `project.*`, `command.*`,
`config.*`, `skill.*`, `websearch.*`, `vcs.*`, `filesystem.*`,
`reference.*`, `location.shutdown`, `session.created/deleted/forked/moved` —
bred creates and owns its sessions). Three are user-visible in a session:

- **`session.compaction.started/delta/ended/failed`** — filed as **c10**. The
  reference client inserts a transcript item that says compaction is running,
  streams its summary and marks it done or failed. bred has no compaction
  handling anywhere outside `lib/opencode`, so a long session's transcript
  jumps with no explanation.
- **`session.synthetic`** — filed as **c11**. The reference inserts a
  synthetic item with text and description; bred drops it.
- **`session.tool.input.delta`** — filed as **c12**. The reference streams the
  tool's input preview; bred waits for `.ended`.

Two more were checked and left as they are, with a note on the row:

- `session.step.streamed` (c2) only sets `assistant.time.streamed` in the
  reference client. That supports the verdict "no legacy event needed"; c2
  stays a triage because a verdict still needs recording and the gate needs a
  red proof.
- `session.agent.selected`, `session.deleted`, `form.replied`,
  `permission.replied` are the client's own actions or another client's; low
  value until a second client is in play.

The fixture set still covers 20 events, so `bin/oc-conformance.mjs` cannot see
any of these three yet; a recording that includes a compaction would be the
first fixture for c10.
